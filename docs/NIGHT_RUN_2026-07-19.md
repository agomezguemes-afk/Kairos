## Misión

1. Pulir la lógica **in-use** (Modo Sesión / during-exercise): fácil de usar, ≤2 toques
   por set, nada de scroll, menos abrumador, desplegables para lo relevante.
2. UI/UX móvil acorde al design system (paper cálido + oro escaso + Fraunces).
3. Sentar base de **complemento Apple Watch** para uso in-training, **o** agente de
   voz que actualice bloques dentro de la app — lo que el análisis estratégico
   determine como mayor valor/menor riesgo overnight.
4. Todo alineado con el README/CLAUDE.md más reciente y la visión (moat = tracking
   híbrido + memoria; voz in-session; marco YC).
